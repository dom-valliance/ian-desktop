# App

The Xcode project and the macOS app target `Ian`. Built in D1.

Keep this target thin: the `@main` entry point, the Info.plist keys and assets. The Info.plist is generated by Xcode from build settings in `project.yml`, and version 0 has no entitlements file. Every view, model and behaviour lives in `Packages/IanKit`, so the project file changes rarely and tests run through SwiftPM.

| Setting | Value |
|---|---|
| Product name | `Ian` |
| Bundle identifier | `ai.valliance.ian.desktop`, `ai.valliance.ian.desktop.dev` for Debug |
| Minimum macOS | 14 |
| Signing in version 0 | Sign to Run Locally (ad hoc). No team, no provisioning profile |
| Build configurations | Debug carries the `mock` and `lance-dev` profiles. No production profile exists until the fast follow (ADR 0003) |

## Generated project

`Ian.xcodeproj` is generated from `project.yml` by `scripts/generate-project.sh` (XcodeGen, pinned in `scripts/tools`). Change `project.yml`, regenerate and commit both. Do not edit the project in Xcode by hand; the next regeneration discards the edit. `scripts/check-generated.sh` regenerates the project and fails CI when the committed copy has drifted (ADR 0007).
